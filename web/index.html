How to install the plugin
  1. In RuneLite, install Wildy Slayer (and Shortest Path, for "Show path") from the Plugin Hub. It is pending review there; until it is listed it runs only in a development client built from the source. Details: the plugin page.
  2. Open Wildy Slayer's settings, paste the code above into Pairing code and enable sync.
  3. Log in and open your bank once so the plugin can read it.
